# スケジュール把握

Excel の予定を時間軸に並べて見る、フリーソフトです。線の移動、色、工数、PDF、ガントチャートの出力ができます。インストールは不要です。ブラウザも通信も使いません。

## 同梱物

- `スケジュール把握.exe` … ダブルクリックで起動します
- `README.md` … この説明
- `LICENSE` … ライセンスの正文（英語）
- `LICENSE.ja.txt` … ライセンスの日本語訳

配るときは、この4つを同じフォルダに入れたまま渡してください。

## 動作環境

Windows 10 以降。Python のインストールは不要です。

PDF の文字には、Windows に入っている游ゴシック、メイリオ、または MS ゴシックを使います。

## 起動

`スケジュール把握.exe` をダブルクリックします。初回は展開に少し時間がかかることがあります。

「Excelを開く」から、予定の入った Excel を選びます。

## Excel の並び

1列目がタスク名、2列目が日付、3列目が時間、4列目がその時間の説明です。5列目に番号を書くと、その段に配置します。空欄なら自動で配置します。同じタスク名が続いている行を結びます。

保存すると、ファイル名の末尾に `_編集` が付きます。すでに `_編集` で終わっている名前は、重ねて付けません。同じ名前があるときは、上書きの確認が出ます。

操作の説明は、画面の「スケジュール把握」と「ツール」の横にある i マークにマウスを乗せると表示されます。

## ソースから動かす

Python 3.11 を使います。

```
py -3 -m pip install -r requirements.txt
py -3 app.py
```

exe を作り直すときは、同じフォルダで `ビルド.bat` を実行します。
